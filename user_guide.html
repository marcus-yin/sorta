Portal Overview

The MTIF Portal is a web-based system for managing Metro Transit Infrastructure Fund applications and related records. Through the portal you can:

  • Submit applications for MTIF funding
  • Request reimbursements for approved project expenses
  • File quarterly progress reports during construction
  • Complete closeout reports when a project is finished

Each reimbursement request, quarterly report, and closeout report is linked to a parent MTIF application. When you create one of these child records from the main landing page, the system automatically associates it with the correct application.

Navigating the Portal

Main Landing Page

After logging in, you'll see the My Applications landing page listing all your MTIF applications. From here you can:

  • Create New Application — Start a new MTIF funding application
  • Edit — Return to an existing draft application (disabled once submitted)
  • Reimbursement — Create a new reimbursement request linked to that application
  • Quarterly Report — Create a new quarterly progress report
  • Closeout Report — Create a new closeout report

List Pages

Separate list pages are available for viewing all your reimbursement requests, quarterly reports, and closeout reports. Each list shows records you created, with an Edit button to return to the form.

Saving & Submitting

Save Draft

Every form includes a Save Draft button. Clicking it saves your current progress to your browser's local storage. A confirmation toast will appear to confirm the save was successful.

Important: Drafts are stored in your browser. If you clear your browser data or switch to a different computer, your draft will not be available. Save early and save often.

Clear Draft

The Clear Draft button removes the saved draft from your browser and resets the form to its default state.

Submit (Application Only)

The MTIF Application has a Submit Application button. Once submitted, the application status changes to "Submitted" and the Edit button on the landing page is disabled. You will be redirected back to the portal home page.

Print / Save as PDF

Some forms include a Print / Save as PDF button. This opens your browser's print dialog where you can choose "Save as PDF" as the destination to download a copy of the completed form.

General Tips

  • Fields with a gray background are read-only and populated automatically from the database.
  • Percentage fields are calculated automatically — you do not need to enter them.
  • File upload fields accept common formats (PDF, images, shapefiles). Each file is uploaded immediately upon selection.
  • Phone number fields auto-format to (XXX) XXX-XXXX as you type.
  • Currency fields should contain whole numbers only unless otherwise noted.
  • The Record ID and Related Application ID at the top of each child form are system-generated and cannot be edited.

Closeout Report

The closeout report is required upon completion of construction for project accounting purposes. Create one from the main landing page by clicking Closeout Report next to your application.

Important: Failure to complete and file the closeout report could result in the loss of future TIF awards.
